# EX06：游戏测试、Debug 与迭代开发（番外）

> [[课程总览|返回课程总览]] · [[05-番外/EX05 - Kristal 的社区库都有啥|上一篇]]

## 开场

展示目前已经完成的 Dog Battle，并列出接下来要通过测试解决的主要问题。

## 建立测试路线

整理从启动项目到战斗结束的固定测试路径，确保每次修改都能覆盖关键流程。

## 观察与记录问题

通过实际游玩记录操作问题、表现问题、流程问题和体验问题，区分不同类型的反馈。

## 使用 Debug 工具定位问题

演示如何借助 Debug 信息确认问题出现的位置和触发条件，缩小排查范围。

## 检查战斗稳定性

反复测试回合切换、ACT 选择、弹幕碰撞、胜负分支和重新开始等情况。

## 调整难度与节奏

根据测试结果调整攻击密度、回合长度、反馈和敌人行为，使战斗更清晰、更连贯。

## 进行一轮迭代

选择最重要的问题完成修改，再重新体验并比较修改前后的结果。

## 结尾

预告下一集：整理项目并打包发布第一个 Kristal 游戏。
