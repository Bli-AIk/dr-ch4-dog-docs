## 棍幕：拉伸机制

先解释下标题：**棍状弹幕**——一根根棍子形状的弹幕（我们这儿就是骨头）。它是 Undertale 同人圈最常见的一类弹幕，至于为什么最常见大家都明白呃呃呃呃……

Deltarune 的棍状弹幕其实没那么常见，但这个经典类型也许能帮助各位快速上手，嗯哼？

*并不，其实做单个小弹幕要简单多了，哈哈。第三回合的骨头就是单个贴图的小弹幕。*

既然说到这，就看看"单个小弹幕"到底多简单——框架自带的 smallbullet（模板 `mod_template/scripts/battle/bullets/smallbullet.lua`），全文就这么点：

```lua
local SmallBullet, super = Class(Bullet)

function SmallBullet:init(x, y, dir, speed)
    -- 最后一个参数是贴图路径
    super.init(self, x, y, "bullets/smallbullet")

    -- 移动：方向（弧度）+ 速度（30fps 下每帧像素）
    self.physics.direction = dir
    self.physics.speed = speed
end

function SmallBullet:update()
    -- 每帧都会调用；要加行为就写这里
    super.update(self)
end

return SmallBullet
```

一个最小的弹幕就三件事：`Class(Bullet)` 继承子弹基类、`init` 里 `super.init(x, y, 贴图)` 再设参数、`update` 里 `super.update` 收尾——然后它就自己飞了（physics 会管移动。这点类似于gms的那些vspeed之类的东西）。

还有个隐藏福利：**默认子弹会自动生成碰撞体**——`Bullet` 的 init 里自动建了一个占自己一半大小的 Hitbox，贴图多大、碰撞就跟着变成一半大，smallbullet 从头到尾没写一句碰撞代码就能被打到。

为什么默认缩一半？引擎注释也就一句 "Default collider to half this object's size"，没多解释——大概是经验使然：贴图画得比判定大一圈，躲避和擦弹都更宽容，玩家体感好。想改就 `setHitbox` 覆盖，骨头就是这么干的。

说到碰撞体，给 UT 社区过来的开发者提个醒：游戏里按 **F6**（开发模式）可以打开调试显示，把碰撞体全画出来。然后……你会看到 DR 的一个特点：**灵魂（玩家）的碰撞体和它的受击判定一样大**——可没有那种"判点比机体小一圈"的说法。

这个特点算好算坏我说不好，反正我玩 DR 时，从来没打出过打东方 STG 的那种手感（草）。

说回正题。先说骨头本体。骨头弹幕麻烦就麻烦在"拼装"上。`scripts/battle/bullets/bonebullet.lua`——两种骨头的公共基类，全文如下（翻译写在注释下面）：

```lua
local BoneBullet, super = Class(Bullet)

-- 锚点：骨头的哪个点"钉"在坐标上
local ANCHOR_ORIGINS = {
    top = 0,        -- 顶部对齐
    center = 0.5,   -- 居中
    bottom = 1,     -- 底部对齐
}

function BoneBullet:init(x, y, length, anchor, top_texture, bottom_texture, fill_x, fill_width)
    super.init(self, x, y)
    self:setScale(1)

    local top_sprite = Sprite(top_texture)
    local bottom_sprite = Sprite(bottom_texture)
    local min_length = top_sprite.height + bottom_sprite.height

    -- 长度：给多少都行，最短不能短过两头帽子拼起来
    self.length = math.max(length or min_length + 4, min_length)
    self.width = math.max(top_sprite.width, bottom_sprite.width)
    self:setSize(self.width, self.length)
    self:setAnchor(anchor or "center")

    -- 中间的填充段：纯色矩形，长度 = 总长 - 两头帽子
    local fill_height = self.length - min_length
    local fill = Rectangle(fill_x, top_sprite.height, fill_width, fill_height)
    fill.layer = -1
    fill.inherit_color = true
    self:addChild(fill)

    -- 顶盖、底盖（这俩贴图一样，只是水平翻转）
    top_sprite:setPosition(0, 0)
    top_sprite.inherit_color = true
    self:addChild(top_sprite)
    self.top_sprite = top_sprite

    bottom_sprite:setPosition(0, self.length - bottom_sprite.height)
    bottom_sprite.inherit_color = true
    self:addChild(bottom_sprite)
    self.bottom_sprite = bottom_sprite

    -- 只有不透明的填充段能伤人
    self:setHitbox(fill_x, top_sprite.height, fill_width, fill_height)
end

function BoneBullet:setAnchor(anchor)
    local origin_y = ANCHOR_ORIGINS[anchor]
    assert(origin_y ~= nil, "Bone anchor must be 'top', 'center', or 'bottom'")
    self.anchor = anchor
    self:setOrigin(0.5, origin_y)
end

-- 低于战斗框的骨头：隐藏且不可碰撞
function BoneBullet:setLayer(layer)
    super.setLayer(self, layer)
    self.collidable = layer >= BATTLE_LAYERS["arena"]
end

return BoneBullet
```

核心思路是"两个顶，一个填充"：顶盖、底盖的贴图是不变的，中间的填充段拉多长都行——生成时给一个 length，骨头就长成多长。

这里的 `Rectangle` 顺带介绍一下：它是 Kristal 的形状对象之一——`Rectangle(x, y, 宽, 高)` 创建一个纯色矩形，能当子对象挂（这里就是挂在骨头上）、能设颜色、能设图层。同一族的还有 `Ellipse(x, y, rx, ry)`（椭圆——想画圆就把 rx、ry 设成一样，引擎里没有单独的"圆"对象）、`Sprite`（贴图）、`Text`（文字）……画形状、当碰撞占位、做演出道具，都用得上。bonebullet 里它干的活是"不透明的填充段"：纯色矩形，拉伸多长都行；`inherit_color = true` 让它跟着父对象变色。

两个细节值得说：

**锚点**。`setAnchor("top"/"center"/"bottom")`——骨头的哪个点"钉"在坐标上：top 顶部对齐、center 居中、bottom 底部对齐。生成时传 anchor 参数，骨头就按指定方式摆放——上面那根从顶部往下长、下面那根从底部往上长，靠的就是它。

**只有不透明的填充段能伤人**。贴图两头有透明像素（骨头帽子），如果整个矩形都算碰撞，玩家会被看不见的地方打到——所以 hitbox 只设在填充段上：

```lua
self:setHitbox(fill_x, top_sprite.height, fill_width, fill_height)
```

"只有看得见的实心部分有碰撞"——做弹幕的常识，先记下。

顺带一提：同一对骨头，上下两根长度往往不一样——因为缝的位置是随机的，上骨长度 = 缝上沿到战斗框顶、下骨长度 = 缝下沿到战斗框底（bone.lua 里 `top_length`/`bottom_length` 就是这么算的）。"拉伸"机制在这里派上大用场：长度是参数，缝挪到哪，骨头就长成什么样。

## 两种骨头

基类有了，两种骨头各一个文件，只填差异（两个文件都是完整形态）：

```lua
-- pap_bone.lua
local BoneBullet = modRequire("scripts.battle.bonebullet")
local PapBone, super = Class(BoneBullet)

function PapBone:init(x, y, length, anchor)
    super.init(self, x, y, length, anchor,
        "bullets/p_top_0", "bullets/p_bottom_0", 4, 5)

end

return PapBone

-- sans_bone.lua
local BoneBullet = modRequire("scripts.battle.bonebullet")
local SansBone, super = Class(BoneBullet)

function SansBone:init(x, y, length, anchor)
    super.init(self, x, y, length, anchor,

    self.inv_timer = 1 / 30
    self.destroy_on_hit = false
    self.damage = 1
end

```

第一行 `modRequire("scripts.battle.bonebullet")` 是模组内的 require——按项目路径手动引入我们自己写的基类。为什么要手动？因为 bonebullet.lua 放在 `scripts/battle/` 下、不在 `bullets/` 目录里——引擎的自动注册只认目录（第 04 集"位置才重要"），它不会自动变成子弹，得我们自己去拿。之后照旧：`Class(BoneBullet)` 继承它，`super.init` 传参（x、y、长度、锚点、顶盖贴图、底盖贴图、填充段的横坐标和宽度），`return` 结尾——和第 04 集见过的敌人文件一个骨架。

pap 的骨头（p_ 贴图）：伤害 66，其他全用默认。sans 的骨头（s_ 贴图）：伤害 1、无敌时间 1/30 秒、打中不消失——这三个数字组合起来就是"帧伤"，sans 的招牌，下面专门说。

## 移动：两种实现方式

然后是移动。子弹怎么动？刚才那个 smallbullet 已经给了答案：Kristal 的 Bullet 自带 physics（物理）系统——最常见的移动方式：给方向+速度，每帧匀速直线飞。模板的 basic wave 就是这么干的：

```lua
-- 模板 waves/basic.lua：向左飞
local bullet = self:spawnBullet("smallbullet", x, y, math.rad(180), 8)
```

`math.rad(180)` 是方向（弧度，180° = 向左），`8` 是速度（30fps 下每帧 8 像素）。smallbullet 内部就是 `self.physics.direction = dir; self.physics.speed = speed`——physics 直线移动。

我们的骨头一开始也试过这个方案（初版确实是 physics 写的）——但最后换成了**缓动（tween）**。为什么？看需求：骨头横穿战斗框，但不是匀速——它要"冲出去，停止一下。然后快到终点时回弹一下"（in-out-back 曲线），中途还要根据位置切换显示层级。这些用 physics 做起来别扭，缓动天然支持。`scripts/battle/waves/bone.lua` 全文：

```lua
local Bone, super = Class(Wave)

-- 骨头横穿战斗框所需的时间（秒）
local TRAVEL_TIME = 2.0
-- 两对骨头生成的间隔（秒）
local SPAWN_INTERVAL = 0.5
-- 夹缝宽度 = 灵魂高度 × 这个倍数
local SOUL_GAP_FACTOR = 1.25
-- 夹缝随机偏移的最大值（像素）
local MAX_GAP_OFFSET = 30
-- 回弹幅度
local BACK_OVERSHOOT = 3.5

-- 自定义 in-out-back 曲线：保持原形状，把回弹幅度加大
local function exaggeratedInOutBack(t)
    local s = BACK_OVERSHOOT * 1.525
    t = t * 2

    if t < 1 then
        return 0.5 * (t * t * ((s + 1) * t - s))
    end

    t = t - 2
    return 0.5 * (t * t * ((s + 1) * t + s) + 2)
end

-- 缓动时按进度切图层：越过 0 切到战斗框上方，越过 1（冲过头）切回下方
local function layerAwareEasing(bullet)
    local previous_value = 0

    return function(t)
        local value = exaggeratedInOutBack(t)

        if previous_value < 0 and value >= 0 then
            bullet:setLayer(BATTLE_LAYERS["above_arena"])
        elseif previous_value < 1 and value >= 1 then
            bullet:setLayer(BATTLE_LAYERS["below_arena"])
        end

        previous_value = value
        return value
    end
end

function Bone:onStart()
    local arena = Game.battle.arena
    local soul = Game.battle.soul

    local arena_left = arena:getLeft()
    local arena_right = arena:getRight()
    local arena_top = arena:getTop()
    local arena_bottom = arena:getBottom()

    -- 夹缝：比灵魂大一圈
    local gap = soul.height * SOUL_GAP_FACTOR

    local function spawnPair()
        -- 1/3 概率是 sans 骨，否则 pap 骨
        local bone_type = MathUtils.randomInt(1, 3) == 1 and "sans_bone" or "pap_bone"
        -- 缝的位置随机偏移
        local gap_offset = MathUtils.randomInt(-MAX_GAP_OFFSET, MAX_GAP_OFFSET + 1)
        local gap_center = (arena_top + arena_bottom) / 2 + gap_offset
        -- 上下骨的长度：按缝的位置算
        local top_length = gap_center - gap / 2 - arena_top
        local bottom_length = arena_bottom - (gap_center + gap / 2)
        local top_bone = self:spawnBullet(bone_type, arena_right, arena_top, top_length, "top")
        local bottom_bone = self:spawnBullet(bone_type, arena_right, arena_bottom, bottom_length, "bottom")

        -- 起点在战斗框右缘，终点在左缘；先藏在战斗框下方
        local start_x = arena_right - top_bone.width / 2
        local target_x = arena_left + top_bone.width / 2
        top_bone:setPosition(start_x, arena_top)
        bottom_bone:setPosition(start_x, arena_bottom)
        top_bone:setLayer(BATTLE_LAYERS["below_arena"])
        bottom_bone:setLayer(BATTLE_LAYERS["below_arena"])

        -- 2 秒横穿，用自定义曲线
        self.timer:tween(TRAVEL_TIME, top_bone, { x = target_x }, layerAwareEasing(top_bone))
        self.timer:tween(TRAVEL_TIME, bottom_bone, { x = target_x }, layerAwareEasing(bottom_bone))
    end

    -- 每 0.5 秒生成一对
    self.timer:everyInstant(SPAWN_INTERVAL, spawnPair)
end

return Bone
```

`tween(时长, 对象, {要改的属性}, 曲线函数)`——2 秒内把 x 缓动到终点，曲线函数决定"怎么动"。先说清楚：**框架自带 in-out-back**——曲线参数直接写 `"in-out-back"` 就有（默认回弹参数 1.70158）。但我试了下，发现幅度不够大，回弹不够带感——于是把算法抄出来，把回弹参数加大到 3.5，成了 exaggeratedInOutBack（in-out-back 的特性：先冲出去、快到终点往回弹一下、再落定）。

想看看更多曲线？https://easings.net/zh-cn，缓动曲线全家福。这里面所有名字都可以用字符串参数（类似"in-out-back"写上去），也可以看其背后的实现原理——具体的算法。这些都可以自定义。

`spawnPair` 里藏着这一回合的"玩法"：**缝的宽度** = 灵魂高度 × 1.25——刚好比灵魂大一圈，能钻过去，但得钻；**缝的位置**每对随机偏移 ±30 像素——缝不固定，得盯着看；骨头类型 1/3 概率是 sans 骨。横穿、夹缝、见缝插针。

配套的 `layerAwareEasing` 是出界切层的小技巧：缓动进度越过 0 时，把骨头切到"战斗框上方"图层；越过 1（冲过头了）切回"下方"——骨头横穿时盖在战斗框上不穿帮，而低于战斗框的骨头不可碰撞（bonebullet 的 setLayer 覆写：`collidable = layer >= BATTLE_LAYERS["arena"]`）。

这就是"对症下药"：直线匀速用 physics，要曲线、要回弹、要中途变卦，用缓动。我们的骨头恰好是后者——试过之后，physics 方案就退役了。

再补充一句：缓动很多时候真的很有用，但它主要是给**演出**、偏向动画的东西准备的——https://easings.net/zh-cn 那些曲线，大多就是干这个用的；physics 则适合物理性更强的物体——惯性、一直旋转、持续受力、一直飞那种。选哪个，是"见仁见智"的问题：没有标准答案，看你想要什么效果，适合自己的就是最好的。

## p骨伤害：66 和保底

伤害行为。pap 骨：66 伤害、命中后有一段无敌时间（引擎默认，防连击）、打中即消失（`destroy_on_hit` 默认 true）——挨一下，疼一下，然后没了。

但 66 有个问题：万一队员就剩 50 血呢？一棍子打死。这回合的设计不想要"秒杀"——所以加了个**保底**：不管打中谁，最多打到剩 1 点血，打不死人。实现是覆写 `getDamage`（还记得第 02 集的 `getAttackDamage` 吗？同款思路——伤害计算的地方，我们自己接管）：

```lua
--- 保底：不管打中谁，都打不死人——最多打到剩 1 点血
function PapBone:getDamage()
    local min_hp = math.huge
    for _, battler in ipairs(Game.battle.party) do
        min_hp = math.min(min_hp, battler.chara:getHealth())
    end
    if min_hp <= 1 then
        return 0
    end
    return math.min(self.damage, min_hp - 1)
end
```

逻辑：遍历全队找最低血量，伤害钳到"最低血量 - 1"（至少留 1 血）；有人已经 1 血甚至 0 血，直接 0 伤害。为什么看全队？因为打中谁不一定（子弹目标默认随机）——要保证的是"谁都不死"。66 的"疼"还在，但永远差一口气。

## s骨伤害：帧伤

sans 骨：1 伤害、无敌时间 1/30 秒、打中不消失。这三个数字就是**帧伤**。先说"无敌时间"是啥：子弹打中灵魂后，灵魂会进入一小段**受击无敌**（invulnerability，简称 invuln）——这段时间里其他子弹打不进来，免得"挨一下就连着挨"。默认无敌是 40 帧（第四章的配置，30 帧 = 1 秒，也就是约 1.3 秒），躲过一次就安全了。sans 骨把无敌时间压到 1/30 秒（正好一帧），伤害压到 1，而且打中不消失——于是它每帧都能重新咬你一口，1 点 1 点地啃，躲不开就是持续掉血。sans 式攻击的招牌。

## 让第一回合进入下一步

最后，这一回合怎么结束？——答案是：不用我们管。波次有个 `time` 属性（秒，默认 5），引擎按它计时：时间到，波次自动标记完成，全部波次完成后交还流程——回到选单。bone.lua 从头到尾没写"结束"两个字：`everyInstant` 每 0.5 秒生成一对，5 秒后引擎喊停，正好 10 对骨头。

想手动提前结束也行，有两个 API：波次里调 `self:setFinished()` 结束自己这一波（引擎文档原话 "End this wave immediately"），`Game.battle:endWaves()` 结束所有波次——比如"生成完最后一批就收工"的场合就用得上。我们没用到，知道有这回事就行。这就是"让第一回合进入下一步"：回合的骨架是引擎的，我们只填演出。

## 检查本集成果
