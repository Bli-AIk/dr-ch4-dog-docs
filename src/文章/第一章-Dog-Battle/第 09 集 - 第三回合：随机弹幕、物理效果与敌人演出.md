# 第 09 集：第三回合：随机弹幕、物理效果与敌人演出

欢迎回来——我们快步入第一章的尾声了。这是《从零做一个 Deltarune 同人游戏》系列的第 9 集，也是**第一章的第六集**。

第 06、07 集做了第一回合的骨头弹幕和第二回合的 GB 演出，第 08 集把 ACT 与饶恕流程补完——三个回合只剩最后一个没做。这一集：**第三回合，泥头车**。

第 03 集定特色时说过，三个回合的编排感是战斗的灵魂："第一回合的经典骨头，第二回合的蓄力（转圈、发光、吸收粒子）和 GB 炮，第三回合的撞击（镜头震动、爆炸）"。前两集把前两个回合的谱子写完，这一集写最后一张——狗要变成一辆车撞向战斗框，顺便回答一个问题：**弹幕怎么做到"每次不一样"，又不乱？**

## 规划随机弹幕

前两个回合的弹幕是"剧本式"的：骨头按固定路径横穿，GB 有完整的蓄力演出，只有选目标是随机的（第二回合咱写的攻击对象指定；susie 的权重更小）。第三回合，我们想加第三种感觉：**真正的随机**。

但随机 ≠ 全乱。完全随机的弹幕，玩家没法读、没法躲，演出也跟着散掉。真正好用的随机是**分层**的——"秩序"负责让玩家读得懂，随机在秩序里制造变化。车回合的骨头落点就是按这个思路设计的：

1. **有序滚动**：30 次撞击，骨头落点从左到右扫 3 轮（每轮从头再来）——整体覆盖稳定，玩家有规律可循；
2. **局部抖动**：落点在有序位置附近 ±40 随机偏移——同一轮扫动里不呆板；
3. **突变**：35% 概率完全随机跳一个位置——偶尔打破规律，制造意外。

顺带对比第二回合的 TARGET_WEIGHTS：那是**权重随机**，管"打谁"（苏西权重低，是为了给她留说话机会）；车回合的落点随机管"怎么躲"。两种随机各有各的用途。

另外，这一回合几乎不需要新文本——没有对话、没有旁白，唯一的文本是回合提示（战斗框下方的提示行）。三条候选文案是：

```json
    "enemy_dog_turn_1": "* [name:dog]正盯着你。",
    "enemy_dog_turn_2": "* [name:dog]似乎藏着什么\n东西。",
    "enemy_dog_turn_3": "* [name:dog]正在摇尾巴。",
```

"正在摇尾巴"——撞人之前的预告。这三条存在 `scripts/battle/enemies/dog.lua` 的 `self.text` 数组里（注意是**敌人文件**，不是第 05 集那个 Encounter——Encounter 的 text 是开场旁白，这里的 text 才是每回合提示）。注意：**默认是随机抽取**——引擎每回合从 `self.text` 里随机挑一条显示在屏幕底部，我们没有指定固定旁白，所以"第三回合必定摇尾巴"这种保证是不存在的：

```lua

    -- 引擎默认行为：每回合从 self.text 随机挑一条显示在屏幕底部
```

## 制作随机攻击组合

先让第三回合真的被选中。第 06 集时 waves 列表里只有 bone（"gb、car 后面再做"），现在三个回合都注册齐了：

```lua
    -- Waves used after the first three turns, which are selected in order below.
    -- 这个列表管两件事：前三回合之后（正常打不到）的随机范围——基类的
    -- selectWave 从这里挑；以及调试工具的 --wave 编号也按它来（3 = car）
    self.waves = {
        "bone",
        "gb",
        "car"
    }
```

前三回合的顺序不靠这个列表，由 `selectWave` 决定——Dog 覆写了基类，按回合数固定顺序：

```lua
function Dog:selectWave()
    local fixed_waves = {
        "bone",
        "gb",
        "car"
    }
    local turn = Game.battle.turn_count

    -- Game.battle.turn_count：当前是第几回合（从 1 开始）
    -- 回合 1 → bone，回合 2 → gb，回合 3 → car
    if turn >= 1 and turn <= #fixed_waves then
        self.selected_wave = fixed_waves[turn]
        return self.selected_wave
    end

    -- 第 4 回合起，交给基类——也就是默认实现：随机挑一个 wave
    return super.selectWave(self)
end
```

回合选择就绪。接下来是 `scripts/battle/waves/car.lua`——这一回合的演出是"编"出来的：从变车、蓄力、撞击到飞回，一长串动作要按顺序串起来。它的常数（时长、距离、次数、随机范围）全部定义在文件头部——这么做的目的是**快速调整**：随机概率、生成范围、撞击次数全是试出来的，这一回合的参数改了很多遍才定下来；全写成顶部常数，调起来就是"改一行 → Ctrl+R 重跑 → 看效果"，不用钻进函数堆里找数字。所以**讲到哪个函数，就解释它用的那些常数**，别一上来就背。先看 init——回合的状态都在这：

```lua
function Car:init()
    super.init(self)

    self.time = 9
    self.dog = nil
    self.original_x = nil
    self.original_y = nil
    self.original_scale_x = nil
    self.original_scale_y = nil
    self.hit_count = 0
    self.bone_target_index = 0
end
```

`self.time = 9`：这一回合的总时长（秒）。整套演出算下来大约 8 秒，刚好装下——就算超时，引擎也会照常收波，所以后面的 `onEnd` 里一定要做恢复。

然后是随机落点的核心 `getBoneTargetX`——规划里的三层随机，代码全在这：

```lua
function Car:getBoneTargetX(arena)
    self.bone_target_index = self.bone_target_index + 1

    -- 目标点默认从 arena 左侧逐步滚动到右侧
    -- 目标点允许出现的最小 x 坐标
    local left = arena:getLeft() + BONE_TARGET_LEFT_MARGIN
    -- 目标点允许出现的最大 x 坐标
    local right = arena:getRight() - BONE_TARGET_MARGIN
    -- 当前目标点所在循环中的序号
    local cycle_index = (self.bone_target_index - 1) % BONE_TARGETS_PER_CYCLE
    -- 当前目标点在本次左到右循环中的进度
    local order_progress = cycle_index / math.max(BONE_TARGETS_PER_CYCLE - 1, 1)
    -- 未发生突变时的有序目标位置
    local target_x = MathUtils.lerp(left, right, order_progress)

    -- 第一层「有序滚动」：默认落点按序号在 left..right 间线性推进
    -- 30 次撞击分 3 个循环（BONE_TARGETS_PER_CYCLE = 10），每循环从左到右扫一遍
    -- 第二、三层随机：35% 突变跳一个完全随机的位置，否则 ±40 小抖动
    if love.math.random() < BONE_TARGET_MUTATION_CHANCE then
        -- 少量骨头直接跳到一个随机位置
        target_x = left + love.math.random() * (right - left)
    else
        -- 大多数骨头只在有序位置附近产生小幅偏移
        target_x = target_x + love.math.random(-BONE_TARGET_JITTER, BONE_TARGET_JITTER)
    end

    -- 无论怎么随机，最后夹在允许范围内
    return MathUtils.clamp(target_x, left, right)
end
```

`getBoneTargetX` 用到的常数都在文件头部：

- `BONE_TARGET_LEFT_MARGIN = -48`——允许探出左边缘一点
- `BONE_TARGET_MARGIN = 12`——右边缘留 12
- `BONE_TARGET_CYCLE_COUNT = 3`——3 轮
- `BONE_TARGET_JITTER = 40`——±40 抖动
- `BONE_TARGET_MUTATION_CHANCE = 0.35`——35% 突变
- `HIT_COUNT = 30`——撞击总次数（后面的 hitArena 会正式用到）

`BONE_TARGETS_PER_CYCLE` 就是 30 ÷ 3 = 10。

落点定了，接下来 `spawnBone` 让骨头沿**抛物线**飞过去——起点在撞击点，经过 arena 底部的目标点，再继续飞出窗口：

```lua
function Car:spawnBone(start_x, start_y)
    local arena = Game.battle.arena
    if not arena then
        return
    end

    -- 本次骨头在 arena 底部的目标 x 坐标（前面规划的随机落点）
    local target_x = self:getBoneTargetX(arena)
    -- 本次骨头在 arena 底部的目标 y 坐标
    local target_y = arena:getBottom()
    -- 抛物线经过目标点时的进度
    local target_progress = BONE_TARGET_PROGRESS
    -- 抛物线顶点所在的进度
    local vertex_progress = BONE_VERTEX_PROGRESS
    -- 让 x 在目标进度时恰好经过目标点，并在之后继续向窗口外移动
    local exit_x = start_x + ((target_x - start_x) / target_progress)
    -- 起点到 arena 底部目标点的垂直位移
    local vertical_delta = target_y - start_y
    -- 抛物线的二次项系数
    local parabola_coefficient = vertical_delta
        / (target_progress * target_progress - 2 * target_progress * vertex_progress)
    -- 抛物线顶点的 y 坐标
    local vertex_y = start_y - (parabola_coefficient * vertex_progress * vertex_progress)
    -- 本次生成的 bone 贴图弹幕
    -- spawnBullet 的第一个参数也可以是贴图路径：引擎没有叫这个名字的子弹类时，
    -- 就用这张贴图生成最基础的子弹（第 06 集传的是子弹类 ID，两种写法都行）
    local bone = self:spawnBullet(BONE_SPRITE, start_x, start_y)
    bone.damage = 66

    -- 骨头沿同一条抛物线飞行时已经经过的时间
    local elapsed = 0
    self.timer:during(BONE_FLIGHT_TIME, function()
        if not bone.parent then
            return false
        end

        elapsed = elapsed + DT
        -- 轨迹的时间进度
        local progress = math.min(elapsed / BONE_FLIGHT_TIME, 1)
        -- 只控制沿抛物线运动的速度，不改变抛物线形状
        local path_progress = Utils.ease(0, 1, progress, "out-cubic")
        -- 当前点相对于抛物线顶点的进度
        local vertex_offset = path_progress - vertex_progress

        bone.x = MathUtils.lerp(start_x, exit_x, path_progress)
        bone.y = vertex_y + (parabola_coefficient * vertex_offset * vertex_offset)
        bone.rotation = bone.rotation - (BONE_ROTATION_SPEED * DT)
    end, function()
        if bone.parent then
            bone:remove()
        end
    end)
end
```

这里的数学值得拆开看，它是"**用进度参数化运动**"的完整例子：

- 整条抛物线用"进度"描述：顶点在进度 0.28，目标点在进度 0.65。由这两个条件解出二次项系数 `parabola_coefficient`，每帧把当前进度塞进同一个方程，轨迹就确定了；
- **速度与形状解耦**：`path_progress` 经过 out-cubic 缓动（先快后慢），只改变"进度推进的快慢"，不改变抛物线本身——想改手感，改缓动，不用改形状；
- `exit_x` 把 x 的运动延伸到目标点之外——骨头"经过"目标点后继续飞出窗口，而不是停在目标点。

代码里还有两个这集第一次见的东西：`timer:during` 是**每帧调用一次**回调的计时器——手动控制运动就用它，回调里 `return false` 可以提前结束，第三个参数是结束时收尾的回调（这里 `if not bone.parent` 就是判活：子弹被移除后 `parent` 会变 nil，骨头不在了就停手）；`Utils.ease(0, 1, 进度, "曲线名")` 是框架的缓动工具——输入原始进度，输出按曲线缓动后的进度，第 06 集 tween 里的曲线就是它算的。

`spawnBone` 用到的常数：

- `BONE_SPRITE = "bullets/bone"`——骨头贴图的路径（素材准备按番外 EX02 的途径来）
- `BONE_FLIGHT_TIME = 54 / 30 * 1.5`——约 2.7 秒
- `BONE_TARGET_PROGRESS = 0.65`——目标点所在的进度
- `BONE_VERTEX_PROGRESS = 0.28`——顶点所在的进度
- `BONE_ROTATION_SPEED = math.rad(360)`——每秒转一整圈

每根骨头 66 伤害，碰到就是重伤。注意和第 06 集 pap 骨的区别：pap 骨的 66 伤害是做过保底的（覆写 `getDamage`，最多打到剩 1 血）；这里的骨头是引擎最基础的贴图弹幕，没有保底——66 全额生效，真能给玩家打死（笑）。这也是为什么前面的随机设计要"能读"：玩家得看出骨头往哪飞，才有得躲。

## 加入物理效果

撞击要 "有反馈感"，靠三个效果——其中镜头震动和粒子爆炸是引擎自带的，第三个是自定义贴图：

**镜头震动** `Battle:shakeCamera`——给个偏移量，镜头抖一下自动衰减：

```lua

---@param y?        number      The amount of shake in the `y` direction. (Defaults to `4`)
--- 纵向震动幅度，默认 4
---@param friction? number      The amount that the shake should decrease by, per frame at 30FPS. (Defaults to `1`)
--- 每帧衰减量（按 30fps 算），默认 1
function Battle:shakeCamera(x, y, friction)
```

**粒子爆炸** `Object:explode`——这就是 Deltarune 原作里出场过不止一次的"高级爆炸特效"，算是个熟面孔小彩蛋——Kristal 直接内置了，一行就能用。第三个参数 `dont_remove` 控制爆炸后物体要不要移除：

```lua

---@param y? number The explosion's vertical offset.

---@return Explosion?
--- 返回生成的爆炸粒子对象
function Object:explode(x, y, dont_remove, options)
```

**闪光贴图**——撞击瞬间那个星星似的闪光，只显示几帧就消失。这玩意儿官方到底叫啥……我不知道这到底咋叫哎呦我服了，反正先这么叫。`spawnCarBoom` 用 wave 的 `spawnSprite`（贴图路径、x、y、图层）生成闪光贴图，放在最顶层、短暂停留后移除；`getRelativePos` 把 Dog 中心点换算到战斗坐标（第三个参数 `Game.battle` 就是目标坐标系）——闪光要贴准撞击点：

```lua
function Car:spawnCarBoom(edge_x)
    -- car_boom 贴图在战斗坐标中的垂直位置
    local _, boom_y = self.dog:getRelativePos(
        self.dog.width / 2,
        self.dog.height / 2,
        Game.battle
    )
    -- 本次撞击生成的闪光贴图（星星似的，只亮几帧）
    local boom = self:spawnSprite(
        "enemies/dog/car_boom",
        edge_x,
        boom_y,
        EFFECT_LAYER
    )
    -- 每次撞击都从撞击点射出一根骨头——随机弹幕从这里来
    self:spawnBone(edge_x, boom_y)

    self.timer:after(BOOM_TIME, function()
        if boom.parent then
            boom:remove()
        end
    end)
end
```

`spawnCarBoom` 用到的常数：

- `BOOM_TIME = 2/30` 秒——贴图停留约两帧
- `EFFECT_LAYER = BATTLE_LAYERS["top"]`——最顶层（值 1000），闪光要盖住其他一切

`BATTLE_LAYERS` 是引擎的图层表，`"top"` 就是最上面的那层。

注意 `spawnCarBoom` 还顺带发射骨头：撞击和弹幕绑在一起——每次撞击就是一次攻击，物理效果和随机弹幕在同一行代码里汇合。

## 制作敌人演出

演出从"变车"开始。`onStart` 里狗先缩成一个点，切到 car 动画，再反向展开——横向缩放从 2 → 0 → -2 → 2，负号就是镜像，视觉上完成"翻面"：

```lua
function Car:onStart()
    self.dog = self:getAttackers()[1]
    if not self.dog then
        return
    end

    -- 记下原始位置和缩放，收尾时恢复
    self.original_x, self.original_y = self.dog:getPosition()
    self.original_scale_x = self.dog.scale_x
    self.original_scale_y = self.dog.scale_y
    self.dog.scale_x = 2
    self.dog:setAnimation({
        "speak/",
        1 / FPS,
        true,
        frames = {1},
    })

    -- 翻转：scale_x 2 → 0（缩成一条线）→ 切 car 动画 → 0 → -2（镜像）→ 恢复正向 2
    -- 负缩放 = 水平镜像，配合换动画，狗就"变成"了车
    -- frames = {1}：只定格在 speak 动画的第 1 帧（翻面时保持闭嘴的静态表情）
    self.timer:tween(
        FLIP_HALF_TIME,
        self.dog,
        {scale_x = 0},
        "in-out-cubic",
        function()
            self.dog:setAnimation("car")
            self.timer:tween(
                FLIP_HALF_TIME,
                self.dog,
                {scale_x = -2},
                "in-out-cubic",
                function()
                    self.timer:tween(
                        FLIP_BACK_TIME,
                        self.dog,
                        {scale_x = 2},
                        "in-out-cubic",
                        function()
                            self:beginDrive()
                        end
                    )
                end
            )
        end
    )
end
```

变完车，`beginDrive` 先向右后撤一段（纵向压扁蓄力），再一头冲向战斗框右缘：

```lua
function Car:beginDrive()
    if not self.dog then
        return
    end

    -- 以 Dog 底部中央为缩放轴——压扁/伸展时不会左右漂
    self.dog:setScaleOrigin(0.5, 1)

    -- 战斗框右侧边缘
    local crash_edge = self:getCrashEdge()
    -- car 左前端到 Dog 锚点的距离
    local front_offset = self:getCarFrontOffset()
    -- Dog 冲撞时的目标位置
    local crash_x = crash_edge + front_offset
    -- 第一次冲撞前的后撤位置
    local intro_x = math.max(self.dog.x + INTRO_DISTANCE, crash_x + RETREAT_DISTANCE)

    -- 后撤 + 压扁蓄力，然后冲出去撞
    self.timer:tween(
        INTRO_TIME,
        self.dog,
        { x = intro_x, scale_y = SQUASHED_SCALE_Y },
        "out-cubic",
        function()
            self.timer:tween(
                CHARGE_TIME,
                self.dog,
                { x = crash_x, scale_y = self.original_scale_y },
                "out-cubic",
                function()
                    self:hitArena(crash_edge, crash_x)
                end
            )
        end
    )
end
```

翻转用到的常数：

- `FLIP_HALF_TIME = 4/30` 秒——缩没、展开各一次
- `FLIP_BACK_TIME = 8/30` 秒——回正

加起来约半秒，翻面要快。

`beginDrive` 用到的两个辅助函数也在这个文件里：`getCrashEdge` 取战斗框右缘；`getCarFrontOffset` 用 car 动画贴图的偏移，算出"车头"到 Dog 锚点的距离（car/ 动画的贴图偏移是 `{-9, -23}`，记在 actors/dog.lua 的 offsets 表里）——这样冲撞目标是"车头撞上战斗框边缘"，而不是锚点陷进去：

```lua
function Car:getCrashEdge()
    return Game.battle.arena and Game.battle.arena:getRight() or 0
end
```

```lua
function Car:getCarFrontOffset()
    -- 当前 car 动画的 sprite
    local sprite = self.dog:getActiveSprite()
    -- car sprite 相对于 Dog 锚点的水平偏移
    local offset_x = sprite:getOffset()[1]
    -- Dog 锚点相对于自身尺寸的水平位置
    local origin_x = self.dog:getOriginExact()

    return (origin_x - offset_x) * math.abs(self.dog.scale_x)
end
```

`beginDrive` 用到的常数：

- `INTRO_TIME = 12/30` 秒——后撤蓄力
- `INTRO_DISTANCE = 30`——后撤距离
- `CHARGE_TIME = 3/30` 秒——冲刺只有 0.1 秒，极快
- `SQUASHED_SCALE_Y = 1.8`——压扁程度（默认缩放是 2，1.8 相对 2 矮了一截）

撞击循环 `hitArena` 是本回合的枢纽：撞一次（震动 + 爆炸 + 射骨头）→ 向右后撤 → 再冲，直到撞满 30 次：

```lua
function Car:hitArena(crash_edge, crash_x)
    if not self.dog or not self.dog.parent then
        return
    end

    self.hit_count = self.hit_count + 1
    -- 每次撞击随机决定镜头震动的横向方向
    local shake_x = love.math.random(0, 1) == 0 and -IMPACT_SHAKE or IMPACT_SHAKE
    -- 每次撞击随机决定镜头震动的纵向方向
    local shake_y = love.math.random(0, 1) == 0 and -IMPACT_SHAKE or IMPACT_SHAKE
    Game.battle:shakeCamera(shake_x, shake_y)
    self:spawnCarBoom(crash_edge)

    -- 撞满 HIT_COUNT 次，进入收尾演出
    if self.hit_count >= HIT_COUNT then
        self:finishHits(crash_edge)
        return
    end

    -- 后撤 → 再冲 → 回调自己，组成撞击循环
    self.timer:tween(
        RETREAT_TIME,
        self.dog,
        { x = crash_x + RETREAT_DISTANCE },
        "out-cubic",
        function()
            self.timer:tween(
                CHARGE_TIME,
                self.dog,
                { x = crash_x, scale_y = self.original_scale_y },
                "out-cubic",
                function()
                    self:hitArena(crash_edge, crash_x)
                end
            )
        end
    )
end
```

震动方向也是随机的（±4 的两个方向独立抽）——这就是"随机只影响小处"：骨架（撞 30 次）不变，每次的震感方向不一样。撞击循环的常数：

- `RETREAT_TIME = 3/30` 秒——每次后撤
- `RETREAT_DISTANCE = 30`——后撤距离
- `HIT_COUNT = 30`——总次数
- `IMPACT_SHAKE = 4`——每次撞击的震动幅度

一次"撤 + 冲"循环 0.2 秒，30 次正好 6 秒。

撞满之后 `finishHits`：一次大爆炸（粒子 + 最顶层贴图），狗转着圈沿抛物线飞回原位，落地 bark 一声：

```lua
function Car:finishHits(crash_edge)
    if not self.dog then
        return
    end

    -- 框架自带的爆炸效果
    -- 第三个参数 true = dont_remove：爆炸后狗不消失，还要飞回来
    local explosion = self.dog:explode(0, 0, true)
    if explosion then
        explosion.layer = EFFECT_LAYER
    end
    self.dog:setAnimation({
        "spin/spin",
        SPIN_FRAME_TIME,
        true,
    })

    -- Dog 飞回原位时已经经过的时间
    local elapsed = 0
    -- 抛物线运动的起点
    local start_x, start_y = self.dog:getPosition()
    self.timer:during(RETURN_TIME, function()
        elapsed = elapsed + DT
        -- 当前飞行动画的归一化进度
        local progress = math.min(elapsed / RETURN_TIME, 1)
        -- 水平移动使用的平滑进度
        local eased = Utils.ease(0, 1, progress, "out-cubic")

        self.dog.x = MathUtils.lerp(start_x, self.original_x, eased)
        self.dog.y = self.original_y - (PARABOLA_HEIGHT * 4 * progress * (1 - progress))
    end, function()
        self:restoreDog()
        self.dog:setAnimation("bark")
        Assets.playSound("snd_pombark")
    end)
end
```

飞回那行 `PARABOLA_HEIGHT * 4 * progress * (1 - progress)`：progress 从 0 到 1 时，`4p(1-p)` 在中间取到最大值 1——起点和终点高度都是 0，最高点正好是 PARABOLA_HEIGHT，一条纯数学的抛物线，不需要粒子系统。注意两条轴各管各的节奏：x 用 out-cubic 缓动（先快后慢，落地有"刹住"的感觉），y 用原始进度（对称的弧）。

收尾的常数：

- `SPIN_FRAME_TIME = 1/30` 秒——spin 动画帧间隔
- `RETURN_TIME = 30/30` = 1 秒——飞回
- `PARABOLA_HEIGHT = 72 * 2 = 144`——最高高度

`snd_pombark` 音效文件从素材途径拿（番外 EX02 讲过素材来源）——暂时没有的话，删掉 `Assets.playSound` 那行不影响演出。

`restoreDog` 把位置、缩放、动画全部还原——兜底值 `2` 是敌人的默认缩放（引擎按 2 倍渲染敌人，万一原始值没记到也能还原）。`onEnd` 也会调用它兜底：引擎收波时会调用 wave 的 `onEnd`（第 07 集欠下的 onEnd，就在这里补上）：

```lua
function Car:restoreDog()
    if not self.dog then
        return
    end

    self.dog:setPosition(self.original_x, self.original_y)
    self.dog.scale_x = self.original_scale_x or 2
    self.dog.scale_y = self.original_scale_y or 2
    self.dog:setAnimation("idle")
end
```

```lua
function Car:onEnd()
    if not self.dog then
        return
    end

    self:restoreDog()
end
```

收波时把狗恢复原样——就算演出没走完（比如时间到了引擎强制收波），狗也不会以车形态留在场上。gb.lua 末尾也放了一个同款的 onEnd（就是第 07 集说"讲到再贴"的那个，写法一样）。

## 连接随机性与演出

整场演出的时间线：

```text
... → enemies/dog.lua 说"回合用 car" → waves/car.lua 编排：
     翻转变车 → 后撤蓄力 → 撞击 ×30（震动 + 爆炸 + 骨头）→ 大爆炸飞回 → bark 收尾
```

支撑这条时间线的是**tween 链**：每个 `timer:tween` 的最后一个参数是回调，回调里再开下一个 tween——上一个播完，下一个才开始。`onStart` 里三层翻转、`beginDrive` 里后撤接冲刺、`hitArena` 里后撤接再冲，全是同一个模式。你在第 06、07 集已经见过它（骨头的 in-out-back、GB 的转圈），这一集把链拉到了最长——整套演出就是一条编好的曲。

链式 tween 管"依次发生"的事；`timer:during` 管"逐帧手写"的运动——骨头的抛物线、狗的飞回，都是用进度参数化后逐帧算位置。两种计时器一组合，任何演出都能编排出来。

最后回到开头的问题：**随机弹幕怎么做，又不乱？** 车回合给出了答案：

- **随机只作用于小处**——骨头落点、震动方向。骨架（次数、时长、顺序）是常数，随机碰不到；
- **玩家感知的是随机**——每次打起来手感不同，"这是活的"；
- **演出的骨架恒定**——节奏从不跑偏，编排不会因为随机而散掉。

难度也一样：每根骨头 66 伤害，数值是常数；能不能躲，取决于随机生成的落点好不好读。
