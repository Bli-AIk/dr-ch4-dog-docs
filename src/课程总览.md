# Kristal 中文教程总览

本系列以制作一个完整的 Dog Battle 为主线，逐步介绍 Kristal 的基础使用、战斗开发、地图制作和进阶扩展。每一集围绕一个可以观察到的成果展开，后续章节会在前面内容的基础上继续扩展项目。

## 序章：准备

- [第 00 集：欢迎来到 Kristal](文章/序章/第%2000%20集%20-%20欢迎来到%20Kristal.md)

  介绍 Kristal 的定位、课程目标和最终项目，让观众了解本系列的学习路线。

- [第 01 集：Windows 开发环境搭建（VSCode）](文章/序章/第%2001%20集%20-%20Windows%20开发环境搭建（VSCode）.md)

  完成 Windows 下的基础开发环境配置，并准备好可以运行和编辑 Kristal 项目的工作区。

- [第 02 集：如何使用 Kristal Wiki、API Reference 与示例项目](文章/序章/第%2002%20集%20-%20如何使用%20Kristal%20Wiki、API%20Reference%20与示例项目.md)

  介绍查找引擎功能、阅读 API 文档和参考示例项目的方法，建立独立查资料的习惯。

- [第 03 集：如何拆解一个 Deltarune 同人游戏（Dog Battle 项目规划）](文章/序章/第%2003%20集%20-%20如何拆解一个%20Deltarune%20同人游戏（Dog%20Battle%20项目规划）.md)

  从整体体验出发拆分 Dog Battle 的战斗、敌人、弹幕和流程，确定第一章的制作目标。

## 第一章：Dog Battle（战斗篇）

- [第 04 集：创建项目与进入第一场战斗](文章/第一章-Dog-Battle/第%2004%20集%20-%20创建项目与进入第一场战斗.md)

  创建课程项目，认识基础目录结构，并让游戏从启动画面进入第一场可运行的战斗。

- [第 05 集：创建敌人、Encounter 与 ACT 菜单](文章/第一章-Dog-Battle/第%2005%20集%20-%20创建敌人、Encounter%20与%20ACT%20菜单.md)

  建立敌人和 Encounter 的基本组成，加入 ACT 菜单，让玩家拥有完整的基础战斗选择。

- [第 06 集：第一回合："经典弹幕"](文章/第一章-Dog-Battle/第%2006%20集%20-%20第一回合：%22经典弹幕%22.md)

  制作 Dog Battle 的第一组经典弹幕，串起攻击区域、玩家移动和回合演出。

- [第 07 集：第二回合：演出、炮击](文章/第一章-Dog-Battle/第%2007%20集%20-%20第二回合：演出、炮击.md)

  制作第二回合的演出与炮击（gaster_blaster 社区库），练习组织多层战斗行为。

- [第 08 集：把 ACT 全部做完：选项与饶恕流程](文章/第一章-Dog-Battle/第%2008%20集%20-%20把%20ACT%20全部做完：选项与饶恕流程.md)

  补全 ACT 菜单的每个选项（检查、摸狗、讲笑话、队伍版摸狗）与唯一的饶恕流程，给出完整的实现代码。

- [第 09 集：第三回合：随机弹幕、物理效果与敌人演出](文章/第一章-Dog-Battle/第%2009%20集%20-%20第三回合：随机弹幕、物理效果与敌人演出.md)

  制作具有变化性的第三回合，加入随机弹幕、物理效果和敌人表现，提升战斗的动态感。

- 第 10 集：打包发布你的第一个 Kristal 游戏

  整理项目内容，完成构建和发布准备，让 Dog Battle 成为可以交付给他人运行的作品。

## 第二章：Overworld（地图篇）

- 第 11 集：使用 Tiled 制作第一张地图

  使用 Tiled 设计并导出第一张地图，了解地图图层、碰撞和素材在 Kristal 中的对应关系。

- 第 12 集：玩家、地图事件与交互

  把玩家放入地图，加入事件和可交互对象，形成可以探索和回应玩家操作的场景。

- 第 13 集：Cutscene：剧情、文本与镜头

  制作一段包含剧情文本和镜头调度的 Cutscene，学习让地图场景承载叙事。

- 第 14 集：地图与战斗的连接

  将地图中的事件与战斗 Encounter 连接起来，建立从探索状态进入战斗状态的流程。

- 第 15 集：制作完整的游戏流程（地图 → 剧情 → 战斗 → 结束）

  把地图、剧情、战斗和结束状态串联起来，完成一个可从头体验到尾的小游戏流程。

## 第三章：进阶开发

- 第 16 集：如何阅读 Kristal 源码与项目结构

  从项目入口和核心模块开始阅读 Kristal 源码，建立对引擎运行流程和职责划分的认识。

- 第 17 集：Library：封装自己的功能模块

  把可复用的功能整理为 Library，学习在多个脚本或项目部分之间共享自己的模块。

- 第 19 集：Hooks：修改与扩展 Kristal

  通过 Hooks 介入既有流程，在不重写核心功能的前提下扩展引擎行为。

- 第 20 集：UI System：自定义菜单与界面

  认识 Kristal 的 UI 组织方式，并制作符合项目需求的菜单和界面组件。

- 第 21 集：Item、Spell 与 Party

  扩展队伍、物品和技能相关内容，让战斗系统支持更丰富的角色配置与策略选择。

- 第 22 集：Shop 与 NPC 系统

  制作商店和 NPC 交互，补充地图中的服务、对话和资源交换功能。

- 第 23 集：Battle Area、地图高级功能

  继续探索战斗区域和地图系统的高级能力，处理更复杂的场景与战斗需求。

- 第 24 集：Debug 技巧、日志与常见问题排查

  整理开发过程中常用的 Debug 和日志方法，并建立排查运行错误的通用流程。

- 第 25 集：如何阅读 API Reference 与独立查阅 Wiki

  以实际需求为线索查阅 API Reference 和 Wiki，练习从文档中确认用法并解决问题。
