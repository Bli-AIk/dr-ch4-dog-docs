# Kristal 中文教程总览

本系列以制作一个完整的 Dog Battle 为主线，逐步介绍 Kristal 的基础使用、战斗开发、地图制作和进阶扩展。每一集围绕一个可以观察到的成果展开，后续章节会在前面内容的基础上继续扩展项目。

## 序章：准备

### [[00-序章/第 00 集 - 欢迎来到 Kristal|第 00 集：欢迎来到 Kristal]]

介绍 Kristal 的定位、课程目标和最终项目，让观众了解本系列的学习路线。

### [[00-序章/第 01 集 - Windows 开发环境搭建（VSCode）|第 01 集：Windows 开发环境搭建（VSCode）]]

完成 Windows 下的基础开发环境配置，并准备好可以运行和编辑 Kristal 项目的工作区。

### [[00-序章/第 02 集 - 如何使用 Kristal Wiki、API Reference 与示例项目|第 02 集：如何使用 Kristal Wiki、API Reference 与示例项目]]

介绍查找引擎功能、阅读 API 文档和参考示例项目的方法，建立独立查资料的习惯。

### [[00-序章/第 03 集 - 如何拆解一个 Deltarune 同人游戏（Dog Battle 项目规划）|第 03 集：如何拆解一个 Deltarune 同人游戏（Dog Battle 项目规划）]]

从整体体验出发拆分 Dog Battle 的战斗、敌人、弹幕和流程，确定第一章的制作目标。

### [[01-第一章-Dog-Battle/第 08 集 - 第三回合：随机弹幕、物理效果与敌人演出|第 08 集：第三回合：随机弹幕、物理效果与敌人演出]]

制作具有变化性的第三回合，加入随机弹幕、物理效果和敌人表现，提升战斗的动态感。

通过运行测试和 Debug 定位问题，检查战斗节奏与难度，并根据测试结果进行迭代。

### [[01-第一章-Dog-Battle/第 11 集 - 打包发布你的第一个 Kristal 游戏|第 11 集：打包发布你的第一个 Kristal 游戏]]

整理项目内容，完成构建和发布准备，让 Dog Battle 成为可以交付给他人运行的作品。

## 第二章：Overworld（地图篇）

### 第 13 集：使用 Tiled 制作第一张地图

使用 Tiled 设计并导出第一张地图，了解地图图层、碰撞和素材在 Kristal 中的对应关系。

### 第 14 集：玩家、地图事件与交互

### 第 15 集：Cutscene：剧情、文本与镜头

制作一段包含剧情文本和镜头调度的 Cutscene，学习让地图场景承载叙事。

### 第 16 集：地图与战斗的连接

将地图中的事件与战斗 Encounter 连接起来，建立从探索状态进入战斗状态的流程。

### 第 17 集：制作完整的游戏流程（地图 → 剧情 → 战斗 → 结束）

把地图、剧情、战斗和结束状态串联起来，完成一个可从头体验到尾的小游戏流程。

## 第三章：进阶开发

### 第 18 集：如何阅读 Kristal 源码与项目结构

从项目入口和核心模块开始阅读 Kristal 源码，建立对引擎运行流程和职责划分的认识。

### 第 19 集：Library：封装自己的功能模块

把可复用的功能整理为 Library，学习在多个脚本或项目部分之间共享自己的模块。

### 第 20 集：Hooks：修改与扩展 Kristal

通过 Hooks 介入既有流程，在不重写核心功能的前提下扩展引擎行为。

### 第 21 集：UI System：自定义菜单与界面

认识 Kristal 的 UI 组织方式，并制作符合项目需求的菜单和界面组件。

### 第 22 集：Item、Spell 与 Party

扩展队伍、物品和技能相关内容，让战斗系统支持更丰富的角色配置与策略选择。

### 第 23 集：Shop 与 NPC 系统

制作商店和 NPC 交互，补充地图中的服务、对话和资源交换功能。

### 第 24 集：Battle Area、地图高级功能

继续探索战斗区域和地图系统的高级能力，处理更复杂的场景与战斗需求。

### 第 25 集：Debug 技巧、日志与常见问题排查

整理开发过程中常用的 Debug 和日志方法，并建立排查运行错误的通用流程。

### 第 26 集：如何阅读 API Reference 与独立查阅 Wiki

以实际需求为线索查阅 API Reference 和 Wiki，练习从文档中确认用法并解决问题。
